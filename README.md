
# 📊 Multi-Service Booking Analysis

An end-to-end analytics project transforming raw, messy booking data into impactful business insights using SQL, Excel, and Power BI.

## 🚀 Project Objective

To analyze service booking data, uncover key business insights, and deliver actionable recommendations using visual storytelling through an interactive Power BI dashboard.

---

## 🔧 Tools & Skills Used

- **SQL (PostgreSQL)**: Data cleaning, COALESCE, date formatting, removing duplicates.
- **Excel**: Preliminary review, exploratory data analysis, pivoting.
- **Power BI**: KPI cards, slicers, bookmarks, drill-throughs, report storytelling.
- **Data Storytelling**: Translating data into business actions and insights.

---

## 🗃️ Dataset Overview

- **Records Analyzed**: 1,000+
- **Data Fields**:
  - Booking Type (Facility / Class / Service)
  - Booking Date & Duration
  - Customer Details
  - Price
  - Booking Status
- **Data Types**: Dates, numerical, categorical

## 📈 Key Insights

### 🔹 Revenue Drivers
- **Facility & Class bookings** generate the majority of revenue.
- **Repeat customers** significantly contribute to revenue → retention matters!

### 🔹 Cancellation Patterns
- Cancellations spike during **peak hours** and **last-minute bookings**.
- **New customers** cancel more frequently than returning ones.

### 🔹 Performance Analysis
- **Top facilities** earn up to **3x more revenue** than underperformers.
- **Popular instructors** have higher rebooking rates and lower cancellations.
- **Long-duration bookings** show lower **revenue per minute**, hinting at inefficiencies.

---

## ✅ Recommendations

- **Optimize Scheduling**: Promote off-peak bookings to reduce cancellations.
- **Customer Loyalty**: Launch reward programs for repeat bookers.
- **Service Evaluation**: Investigate & revamp underperforming services.
- **Targeted Marketing**: Focus campaigns on high-retention segments.
